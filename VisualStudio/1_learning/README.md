# 走路距离记录练习

使用 C 语言记录每天的走路距离，计算总距离、平均距离及最大距离，并可把每日记录保存为文本表格。

## 运行

使用安装了 C++ 桌面开发工具的 Visual Studio 打开 `1_learning.slnx`，选择此项目后生成并运行。项目当前使用 v145 工具集及 Windows SDK。

输入天数（1～1000）和每天的距离（0～1000 公里）；选择 `y` 或 `Y` 时，程序将记录写入 `D:/vscoding/files_io/try.txt`。每次保存会覆盖旧内容。

文件路径为本机练习路径，在其他设备上运行前，请按实际目录修改 `main.c` 中的路径。程序使用 Windows 专用函数，当前项目面向 Windows。

## 学习内容

- 结构体和动态内存分配
- 输入检查、循环、统计计算
- 函数参数及文件指针
- `fopen`、`fprintf`、`fclose` 文本写入

仓库只保存源码和项目配置，构建输出及本机设置由 `.gitignore` 排除。
